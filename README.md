# Pass the Bomb 💣

A multiplayer-inspired bomb passing game developed as a project requirement. Players must avoid holding the bomb when the timer runs out. The game includes power-ups, sound effects, menus, and networking features.

## Features
- Multiplayer/networked gameplay
- Bomb passing mechanics
- Freeze power-up
- Background music and sound effects
- Main menu interface
- Interactive gameplay

## Requirements
Before running the game, make sure you have the following installed/cloned:

- Git
- Java and JavaFX (ensure the versions are compatible with the project)
- Repository:
  https://github.com/Justine0926/137-pass-the-bomb.git

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Justine0926/137-pass-the-bomb.git
```

2. Open the project folder:

```bash
cd 137-pass-the-bomb
```

3. Unzip `PassTheBomb.zip`
   - This contains the executable file for Windows and the JAR file.

---

## How to Run

### Option 1 – Run the Executable

After unzipping `PassTheBomb.zip`, run:

```bash
./PassTheBomb.exe
```

### Option 2 – Run the Source Code

Compile and run the project using Java:

```bash
javac Main.java
java Main
```

### Option 3 – Use the Bash File

```bash
chmod +x run.sh
./run.sh
```

---

## Multiplayer

Players can either host or join a game through the multiplayer menu.  
The host will provide the IP address that other players can use to connect.
